# VXShot 1.0.0

- Mở ảnh PNG/JPEG từ máy hoặc clipboard để chú thích nhanh.
- Thêm mũi tên, hình vẽ, chữ, số bước, tô sáng, khối che đặc và mosaic; hỗ trợ hoàn tác/làm lại.
- Lưu PNG/JPEG hoặc sao chép ảnh đã hợp nhất để dán sang ứng dụng khác.
- Giữ nguyên chú thích khi chuyển ứng dụng hoặc quay lại từ hộp thoại lưu.
- Ảnh xử lý trên máy. Kiểm tra và cài phiên bản mới ngay trong mục Cập nhật.

Bản đầu hỗ trợ chỉnh một ảnh; ghép nhiều ảnh và thay đổi kích thước canvas sẽ được bổ sung sau.
