- Đồng bộ giao diện Cài đặt (Settings) chuẩn hóa: hỗ trợ song ngữ Tiếng Việt - Tiếng Anh và các phím tắt công cụ.

- Hoàn thiện typography và hình học thanh tiêu đề đồng nhất với bộ ứng dụng VXUtilities.
- Tích hợp thẻ thông báo Cập nhật trực tiếp góc dưới và tối ưu hóa biểu tượng Giới thiệu (About).
